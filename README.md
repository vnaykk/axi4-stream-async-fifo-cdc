# Parameterized AXI4-Stream Asynchronous FIFO (CDC Bridge)
![CI Status](https://img.shields.io/badge/Simulation-Passing-brightgreen)
Synthesizable **AXI4-Stream Asynchronous FIFO** in SystemVerilog for packet transfers across asynchronous clock domains (`156.25 MHz` <-> `100 MHz`) using Gray-code pointers and 2-FF synchronizers.
